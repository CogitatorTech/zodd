ZODD SYSTEM SPECIFICATION

[SYS.SPEC.001]

Zodd is a specialized, embeddable Datalog engine written in pure Zig. This interface targets the core engine compiled to WebAssembly, executing recursively within your sandbox.

The compiler parses relations, processes stratified negation (not), and evaluates aggregations (count, sum, min, and max).
